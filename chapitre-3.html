QUESTION DIRECTRICE

Comment savoir si un modèle a véritablement appris ?

Une géologue prédit une classe lithologique, un biologiste identifie une espèce, une chimiste estime une propriété moléculaire et une physicienne approxime une mesure instrumentale. Dans chaque cas, une prédiction convaincante doit être évaluée sur des observations non utilisées pendant l’entraînement.

Objectifs. Formaliser un problème supervisé ou non supervisé ; comprendre les principes de la régression, de la classification et du clustering ; entraîner des modèles simples ; sélectionner des métriques adaptées ; prévenir les fuites de données et justifier une conclusion scientifique.

1. Définir le problème avant l’algorithme

En apprentissage supervisé, nous disposons de couples (xᵢ, yᵢ) : les caractéristiques xᵢ décrivent une observation et yᵢ une valeur à estimer. La régression prédit une grandeur continue (conductivité, concentration, solubilité). La classification prédit une catégorie (espèce, faciès, état d’un échantillon). En apprentissage non supervisé, les observations ne disposent pas de catégories cibles : on explore leurs régularités et regroupements sans leur attribuer automatiquement un sens physique.

BiologieClasser des espèces à partir de mesures
ChimieEstimer une concentration ou une propriété
GéologieRegrouper des signatures géochimiques
PhysiqueApproximer une réponse instrumentale

2. Régression : apprendre une relation quantitative

Pour un modèle linéaire, la prédiction s’écrit ŷ = β₀ + β₁x. Les coefficients minimisent une fonction de perte telle que l’erreur quadratique moyenne.

MSE = (1/n) Σ (yᵢ − ŷᵢ)²

Une faible erreur d’entraînement n’implique pas une bonne précision sur de nouveaux échantillons. Un modèle plus flexible, tel qu’un arbre de décision ou une forêt aléatoire, peut apprendre des relations non linéaires, mais il demande aussi un contrôle de sa complexité.

Démonstration pas à pas : la droite des moindres carrés

Minimiser la MSE donne une solution explicite : β₁ = Σ(xᵢ − x)(yᵢ − ȳ) / Σ(xᵢ − x)² et β₀ = ȳ − β₁x (en plusieurs variables : β = (XᵀX)⁻¹Xᵀy).

Données : x = (1, 2, 3, 4), y = (2, 4, 5, 8). Moyennes x = 2,5 et ȳ = 4,75.

  1. Écarts : x − x = (−1,5 ; −0,5 ; 0,5 ; 1,5) et y − ȳ = (−2,75 ; −0,75 ; 0,25 ; 3,25).
  2. Somme des produits : 4,125 + 0,375 + 0,125 + 4,875 = 9,5 ; somme des carrés des écarts de x : 5. Donc β₁ = 1,9 et β₀ = 4,75 − 1,9 × 2,5 = 0.
  3. Prédictions ŷ = (1,9 ; 3,8 ; 5,7 ; 7,6) ; résidus (0,1 ; 0,2 ; −0,7 ; 0,4) ; MSE = 0,70/4 = 0,175.
  4. R² = 1 − SSrés/SStot = 1 − 0,70/18,75 ≈ 0,963 : le modèle explique 96 % de la variance de ces quatre points, ce qui ne dit rien de nouveaux points.

3. Classification : prévoir une classe et gérer l’incertitude

La régression logistique convertit un score en probabilité grâce à la sigmoïde : p = 1 / (1 + exp(−z)). Une probabilité supérieure au seuil choisi entraîne une décision ; changer le seuil déplace le compromis entre faux positifs et faux négatifs. Accuracy, précision, rappel et F1 répondent à des questions différentes, particulièrement lorsque les classes sont déséquilibrées.

Précision = VP/(VP+FP)   |   Rappel = VP/(VP+FN)
Démonstration pas à pas : une probabilité, deux décisions

Un modèle logistique appris vaut z = −4 + 0,8 x, où x est une concentration (mg/L). Pour x = 6 : z = 0,8 et p = 1/(1 + e−0,8) ≈ 0,69.

  • Avec un seuil de 0,5, l’échantillon est déclaré contaminé ; avec un seuil de 0,7 (on veut limiter les fausses alertes), il est déclaré conforme. Le modèle n’a pas changé : seule la décision a changé.
  • L’apprentissage minimise la log-loss ℒ = −[y ln p + (1 − y) ln(1 − p)]. Si l’échantillon est réellement contaminé (y = 1), la perte vaut −ln 0,69 ≈ 0,37 ; s’il est conforme (y = 0), elle vaut −ln 0,31 ≈ 1,17. Une prédiction confiante et fausse coûte cher.

Démonstration interactive : seuil, prévalence et matrice de confusion

Les deux courbes représentent la distribution des scores du modèle pour les cas négatifs et positifs. Déplacez le seuil, réduisez la prévalence de la classe positive (une maladie rare, une pollution exceptionnelle) ou la séparation entre classes, et observez les métriques.

4. Apprentissage non supervisé et réduction de dimension

K-means cherche des centres de groupes en minimisant les distances internes. Le nombre de clusters doit être examiné, et les variables standardisées si leurs échelles ne sont pas comparables. L’analyse en composantes principales (ACP) projette les observations sur de nouvelles directions de variance maximale. Un groupe visualisé en ACP n’est pas nécessairement une espèce, une réaction ou une formation géologique.

Démonstration pas à pas : K-means à la main

Six mesures 1D : 1, 2, 3, 10, 11, 12. K = 2, centres initiaux c₁ = 1 et c₂ = 2.

  1. Affectation : 1 → c₁ ; 2, 3, 10, 11, 12 → c₂ (plus proche). Mise à jour : c₁ = 1 ; c₂ = (2 + 3 + 10 + 11 + 12)/5 = 7,6.
  2. Affectation : 1, 2, 3 → c₁ (|3 − 1| = 2 < |3 − 7,6| = 4,6) ; 10, 11, 12 → c₂. Mise à jour : c₁ = 2 ; c₂ = 11.
  3. Les affectations ne changent plus : l’algorithme a convergé. Inertie = (1 + 0 + 1) + (1 + 0 + 1) = 4.

Avec d’autres centres initiaux, K-means peut converger vers une autre partition : on le relance plusieurs fois (n_init) et l’on garde l’inertie la plus faible. Le choix de K s’appuie sur la courbe d’inertie (« coude ») ou le coefficient de silhouette, et la comparaison à des classes connues sur l’indice de Rand ajusté (ARI).

5. Protocole de validation scientifique

  1. Définir l’unité expérimentale et la variable cible.
  2. Séparer entraînement et test avant toute opération apprise sur les données.
  3. Mettre l’imputation, la standardisation et le modèle dans un Pipeline.
  4. Comparer à une baseline simple.
  5. Faire une validation croisée sur le jeu d’entraînement, puis évaluer une fois sur le test.
  6. Identifier les erreurs, les incertitudes et les limites scientifiques.
Attention aux groupes et au temps. Des mesures provenant d’un même patient, site, instrument ou lot peuvent être corrélées : une séparation aléatoire peut surestimer les performances. Utiliser une séparation par groupe ou chronologique lorsqu’elle correspond à l’usage futur.
Comment fonctionne la validation croisée à k plis

L’entraînement est découpé en k blocs. On entraîne k fois, chaque fois sur k − 1 blocs, et l’on évalue sur le bloc restant (en ocre). Le score annoncé est la moyenne des k scores ; leur écart-type indique la stabilité.

Pli 1valid.entr.entr.entr.entr.Pli 2entr.valid.entr.entr.entr.Pli 3entr.entr.valid.entr.entr.Pli 4entr.entr.entr.valid.entr.Pli 5entr.entr.entr.entr.valid.

Le test est mis de côté avant ce découpage et n’est consulté qu’une fois, à la fin. Avec des groupes (patients, sites), on utilise GroupKFold ; avec des séries temporelles, TimeSeriesSplit.

Biais, variance et bruit

Pour une observation nouvelle, l’erreur quadratique attendue se décompose en trois termes :

E[(y − f̂(x))²] = Biais² + Variance + σ²

Le biais mesure l’écart systématique d’un modèle trop rigide ; la variance, sa sensibilité à l’échantillon d’entraînement (modèle trop flexible) ; σ² est le bruit de mesure, irréductible. Dans le TP 1, avec un bruit σ = 7, aucun modèle ne descend sous une MAE d’environ 5,6 : la validation croisée retient un polynôme de degré 2, qui est la vraie forme simulée.

6. Expérience interactive : comparer les modèles

Modifiez le type de tâche, le bruit et la complexité des données simulées. La visualisation illustre des comportements possibles ; elle ne constitue pas une validation empirique.

7. Interpréter au-delà de la métrique

En régression, MAE est exprimée dans l’unité de la grandeur, RMSE pénalise davantage les grosses erreurs, et R² rapporte l’amélioration relative par rapport à une prédiction constante. En classification, une matrice de confusion fait apparaître les types d’erreurs. Interprétabilité et causalité ne sont pas équivalentes : l’importance d’une variable dans un modèle ne démontre pas qu’elle provoque le phénomène observé.

À retenir. La bonne question n’est pas seulement « quel modèle prédit le mieux ? », mais « dans quelles conditions, pour quelles observations et avec quelles conséquences peut-on utiliser cette prédiction ? »

Exercice 1 — Formaliser quatre problèmes (25 min)

Pour chaque situation, préciser X, y s’il existe, l’unité d’observation et la famille d’apprentissage : (a) prévoir la solubilité en mg/L ; (b) identifier une espèce végétale ; (c) regrouper des roches sans étiquettes ; (d) prédire la température du lendemain à partir de mesures chronologiques.

Voir le corrigé expliqué

(a) Régression : X = descripteurs moléculaires, y = solubilité ; unité = molécule. (b) Classification : X = mesures morphologiques, y = espèce ; unité = individu. (c) Non supervisé : X = composition géochimique ; aucune étiquette y ; unité = échantillon de roche. (d) Régression temporelle : X = mesures passées, y = température future ; respecter l’ordre chronologique.

Exercice 2 — Erreurs de régression (25 min)

Valeurs observées : [2, 4, 6, 8]. Prédictions : [3, 3, 7, 7]. Calculer MAE, MSE et RMSE ; comparer à une baseline constante de valeur 5.

Afficher les calculs

Erreurs absolues [1,1,1,1] : MAE = 1 ; MSE = 1 ; RMSE = 1. Baseline 5 : erreurs absolues [3,1,1,3], MAE = 2 ; MSE = 5 ; RMSE ≈ 2,236. Le modèle fait mieux sur cet exemple, sans prouver qu’il généralise.

Exercice 3 — Matrice de confusion (25 min)

Un test comporte 20 observations : VP = 6 ; FP = 2 ; FN = 4 ; VN = 8. Calculer précision, rappel et F1 de la classe positive. À quelles erreurs seriez-vous particulièrement attentif dans une application de sécurité environnementale ?

Voir le corrigé

Précision = 6/8 = 0,75 ; rappel = 6/10 = 0,60 ; F1 = 2×0,75×0,60/(0,75+0,60) ≈ 0,667. Dans la détection d’un danger, les faux négatifs méritent une attention particulière ; les coûts réels doivent guider le seuil.

Exercice 4 — K-means et ACP (20 min)

Pourquoi standardiser des variables exprimées en mg/L et en μg/L avant une distance euclidienne ? Un cluster visualisé en 2D constitue-t-il une preuve d’un groupe naturel ?

Éléments de réponse

Les distances sont sensibles à l’échelle numérique ; une variable peut dominer. La standardisation doit être justifiée et documentée. Un cluster est une partition selon une métrique et un choix de K, pas une découverte validée sans expertise disciplinaire.

Exercice 5 — Audit d'une expérimentation (25 min)

Une équipe normalise l’intégralité d’un dataset, sélectionne les variables sur l’ensemble puis découpe train/test. Elle publie une accuracy de 98 %. Que faut-il remettre en question ?

Analyse critique

La standardisation et la sélection réalisées sur tout le dataset introduisent une fuite d’information. Il faut ré-estimer chaque transformation sur les folds d’entraînement (Pipeline), conserver un test indépendant et étudier les doublons, groupes, distributions et erreurs par classe.

TP 1 — Régression scientifique et validation (3 h)

Le notebook ajoute la courbe biais–variance (degrés 1 à 15), un test d’extrapolation (entraînement sous 50 °C, test au-dessus), puis le jeu réel diabetes avec régularisation Ridge.

Situation. Simulation pédagogique de la réponse d’un instrument en fonction d’une température. L’équation génératrice sert uniquement à contrôler l’expérience ; elle ne prétend pas représenter une loi physique mesurée.

Étape 1 — Générer et inspecter les mesures
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
rng = np.random.default_rng(42)
n = 180
T = rng.uniform(10, 75, n)
y = 1.5 + 0.8*T + 0.015*T**2 + rng.normal(0, 7, n)
df = pd.DataFrame({'temperature_C': T, 'signal_u.a.': y})
print(df.describe())
df.plot.scatter(x='temperature_C', y='signal_u.a.')
plt.show()

Décrire la forme des observations, les unités et l’amplitude du bruit.

Étape 2 — Séparer puis entraîner deux modèles
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.dummy import DummyRegressor
from sklearn.linear_model import LinearRegression
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error, root_mean_squared_error

X = df[['temperature_C']]
y = df['signal_u.a.']
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42)
models = {
    'Référence': DummyRegressor(strategy='mean'),
    'Linéaire': LinearRegression(),
    'Forêt': RandomForestRegressor(n_estimators=100,
                                   min_samples_leaf=3, random_state=42)
}
for name, model in models.items():
    model.fit(X_train, y_train)
    pred = model.predict(X_test)
    print(name, 'MAE =', round(mean_absolute_error(y_test, pred), 2),
          'RMSE =', round(root_mean_squared_error(y_test, pred), 2))

Si votre version de scikit-learn ne fournit pas root_mean_squared_error, utiliser np.sqrt(mean_squared_error(y_test, pred)).

Étape 3 — Évaluer et discuter
scores = cross_val_score(models['Forêt'], X_train, y_train,
                          cv=5, scoring='neg_mean_absolute_error')
print('MAE CV :', -scores.mean(), '±', scores.std())
residus = y_test - models['Forêt'].predict(X_test)
plt.scatter(models['Forêt'].predict(X_test), residus)
plt.axhline(0, color='black', linestyle='--')
plt.xlabel('Prédiction (u.a.)'); plt.ylabel('Résidu (u.a.)')
plt.show()

TP 2 — Classification, ACP et clustering sur des analyses chimiques réelles (3 h)

Situation. Le jeu Wine réunit 13 analyses de laboratoire (alcool, acide malique, phénols, flavonoïdes, intensité de couleur, proline…) pour 178 vins de trois cultivars. Il remplace Iris pour travailler sur des mesures chimiques aux échelles très différentes.

Étape 1 — Classification sans fuite (45 min)
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split, cross_val_score, StratifiedKFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

wine = load_wine(as_frame=True)
X, y = wine.data, wine.target
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=.25, stratify=y, random_state=42)
clf = make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000))
cv = StratifiedKFold(5, shuffle=True, random_state=0)
print(cross_val_score(clf, X_tr, y_tr, cv=cv, scoring='balanced_accuracy').mean())

Comparer à une baseline, lire le rapport de classification, puis repérer avec predict_proba les vins prédits avec la plus faible confiance.

Étape 2 — ACP : variance expliquée et contributions (45 min)

Tracer l’éboulis des valeurs propres, la projection sur les deux premiers axes colorée par cultivar et les contributions (loadings) des variables. Les flavonoïdes et les phénols structurent le premier axe, l’intensité de couleur et l’alcool le second.

Étape 3 — K-means, silhouette et ARI (45 min)

Choisir K avec la courbe d’inertie et la silhouette, puis comparer la partition aux cultivars (ARI ≈ 0,90 sur données standardisées). Démonstration : sans standardisation, l’ARI chute à environ 0,37, car la proline (écart-type ≈ 315) domine la distance euclidienne.

Étape 4 — Discussion (45 min)

Pourquoi les identifiants de clusters ne correspondent-ils pas aux noms des cultivars ? Une partition qui retrouve les cultivars constitue-t-elle une découverte ? Quelles données (autre région, autre millésime) seraient nécessaires pour généraliser ?

Indications pour la correction

Les étiquettes de clusters sont arbitraires ; seule la concordance (ARI, tableau croisé) a un sens. Retrouver des catégories déjà connues valide la méthode sur ce jeu, sans découverte. Les vins proviennent d’une seule région : un changement de terroir ou de millésime est un décalage de distribution.
