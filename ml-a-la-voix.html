LE CARNET / CHAPITRE 3 / LABORATOIRE VOCAL

Machine Learning à la voix.

Illustrez à l'oral les notions de régression, classification et clustering. Simulation locale à vocation pédagogique : les points sont synthétiques, les frontières et les regroupements sont des visualisations simplifiées.

La saisie par boutons reste disponible si le navigateur ne reconnaît pas la voix.

Exemples à dire : « montre une classification », « augmente le bruit », « trois groupes », « trace une régression », « masque la frontière ».

Visualisation expérimentale

Les groupes affichés dans le mode clustering sont les groupes de génération synthétique (et non le résultat calculé d'un algorithme K-means). Les frontières sont illustratives et non apprises par un classifieur.
