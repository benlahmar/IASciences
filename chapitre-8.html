1 HEURE DE COURS · MÉTHODOLOGIE INTÉGRATRICE

Le projet commence par une question scientifique

Le modèle n’est pas le point de départ. Le travail débute par une question précise et testable : « Peut-on prédire la solubilité d’une molécule à partir de descripteurs structuraux ? », « Quels paramètres expliquent la variation d’une grandeur physique ? » ou « Ce classifieur généralise-t-il à un nouveau terrain géologique ? ».

Compétences mobilisées : C2–C8. Préparer les données, sélectionner un modèle, organiser une comparaison loyale, justifier les résultats, communiquer les limites et documenter l’usage de l’IA.

1. Construire une problématique mesurable

Définir (a) le phénomène, (b) l’unité d’observation, (c) les variables explicatives, (d) la cible, (e) le contexte d’usage et (f) le critère de réussite. Une bonne question annonce ce qui constituerait une réponse négative, pas seulement un succès attendu.

Question → Hypothèse → Données → Protocole → Résultats → Discussion

2. Décrire les données et leurs limites

Consigner provenance, unités, effectif, date, appareil, conditions de collecte, valeurs manquantes, identifiants de groupe et droits d’utilisation. Les réplicats, mesures temporelles et observations spatiales imposent souvent une séparation spécifique pour éviter les fuites.

3. Définir une baseline avant le modèle complexe

Pour une régression, prédire la moyenne du jeu d'entraînement est un point de comparaison minimal. Pour une classification, comparer à une règle majoritaire ou à un classifieur simple. Les modèles plus complexes doivent justifier leur coût par un gain vérifié sur des données indépendantes.

4. Protocole expérimental reproductible

  1. Réserver un test indépendant non utilisé pour les choix de méthode.
  2. Installer nettoyage, imputation et normalisation dans un pipeline ajusté uniquement sur l'entraînement.
  3. Comparer une baseline et au moins deux méthodes adaptées.
  4. Choisir les métriques selon le problème : MAE/RMSE pour la régression, F1 et rappel pour la classification, accompagnés de leurs limites.
  5. Faire une analyse d’erreurs : sous-groupes, valeurs extrêmes, conditions nouvelles.
  6. Documenter les graines aléatoires, versions et hypothèses.
Attention : une amélioration du score ne prouve ni une relation causale ni la découverte d’un mécanisme. L’interprétation doit être confrontée aux connaissances de la discipline.

5. Communiquer comme un scientifique

Le rapport comporte : titre, résumé, question, protocole, données, résultats chiffrés, graphiques lisibles avec unités, discussion, limites, bibliographie et déclaration de l’usage d’outils génératifs. Une présentation orale doit répondre à trois questions : que cherchait-on ? qu’a-t-on réellement montré ? que reste-t-il à vérifier ?

6. Six sujets adaptés aux spécialités

BiologieClassification de mesures morphologiques (Iris), variables discriminantes et erreur par espèce
ChimieRégression de solubilité (ESOL), validation et influence des descripteurs
GéologieClassification de roches à partir de données géochimiques, avec contrôle du site d’origine
PhysiqueApproximation d’une loi de décroissance thermique, comparaison au modèle mécaniste
MathématiquesApproximation d’une fonction et généralisation hors intervalle d’entraînement
EnvironnementPrévision d’un indicateur météorologique avec découpage temporel
Si les données réelles ne sont pas accessibles, utiliser un jeu public ou simulé explicitement identifié, avec paramètres de génération et limitations.

GUIDE AUTONOME · EXERCICES CORRIGÉS · HORS VOLUME TD OFFICIEL

Préparer le dossier de projet

Le chapitre ne comporte pas d’heures TD dans la maquette. Ces exercices sont des ressources d’auto-préparation, à travailler avant l’atelier de 2 heures.

Exercice 1 — Du thème à la question scientifique

Une équipe propose « Étudier la chimie avec l’IA ». Reformulez cette idée en question évalu able, avec cible, variables et métrique.

Voir le corrigé

Exemple : « Prédire la solubilité aqueuse logarithmique de molécules organiques à partir de descripteurs structuraux, puis comparer la MAE sur molécules tenues hors entraînement à une baseline moyenne ». Il faudra vérifier que l’ensemble de test est représentatif de l’usage visé.

Exercice 2 — Choisir une séparation

Le dataset géologique contient cinq prélèvements par site. Pourquoi un découpage aléatoire ligne par ligne est-il risqué ?

Voir le corrigé

Les échantillons du même site partagent des propriétés. Une séparation par site (GroupKFold ou groupe de test tenu hors entraînement) teste mieux la généralisation à de nouveaux sites.

Exercice 3 — Modèle gagnant ?

Sur un test limité, trois méthodes donnent MAE = 1,20 (baseline), 0,82 (régression) et 0,80 (Random Forest). Laquelle retenir ?

Voir le corrigé

Random Forest a le score ponctuel le plus bas, mais l’écart 0,02 peut être instable. Examiner variance, intervalles, domaine d’usage, coût et simplicité avant de conclure. Le test final ne doit pas être réutilisé pour la sélection.

Exercice 4 — Intégrité scientifique

Un assistant génératif propose deux références introuvables et interprète une corrélation comme causalité. Quelle réponse méthodologique adopter ?

Voir le corrigé

Ne pas reprendre les références sans vérification ; retrouver les sources primaires et leur DOI si disponibles ; reformuler en termes d’association ; signaler l’usage de l’assistant ; confronter l’explication au protocole et à la théorie scientifique.

Grille de vérification avant dépôt

Chaque item doit pouvoir être démontré dans le rapport : question scientifique explicite ; provenance des données ; séparation valide ; baseline ; métriques ; analyse d’erreurs ; limites ; notebook exécutable ; déclaration de l’usage de l’IA.

Notebook de référence — classification scientifique

Exemple exécutable sur Iris. Le découpage, l'imputation et la normalisation utilisent un pipeline afin d’éviter de calculer les statistiques de prétraitement sur l’ensemble de test.

import numpy as np
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, f1_score, classification_report

X, y = load_iris(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=42
)
models = {
    "Baseline": DummyClassifier(strategy="most_frequent"),
    "Logistique": make_pipeline(SimpleImputer(), StandardScaler(),
                                LogisticRegression(max_iter=2000)),
    "Forêt": make_pipeline(SimpleImputer(), RandomForestClassifier(
                                    n_estimators=200, random_state=42))
}
for name, model in models.items():
    model.fit(X_tr, y_tr)
    y_pred = model.predict(X_te)
    print(name, "accuracy", round(accuracy_score(y_te, y_pred), 3),
          "F1 macro", round(f1_score(y_te, y_pred, average="macro"), 3))
print(classification_report(y_te, models["Logistique"].predict(X_te)))
Il s’agit d’un exemple pédagogique, non d’un résultat de recherche. Dans le projet final, prévoir si possible une stratégie de validation croisée sur la partie entraînement ; garder le test indépendant pour l’estimation finale.
